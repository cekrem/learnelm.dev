# learnelm.dev

A short, opinionated path to learning Elm. Lives at [learnelm.dev](https://learnelm.dev), built from `index.md` with Jekyll.

## Contributing

Got a resource that belongs on the list, or spotted something broken? Open a PR against `index.md`. Match the one-line "why it's here" tone of the existing entries — every link earns its spot, otherwise this page just turns into [awesome-elm](https://github.com/sporto/awesome-elm) (which already exists, and does that job well).

Not sure if your suggestion fits? Catch me on the [Elm Slack](https://elm-lang.org/community/slack) first. Cheaper than a round-trip on a PR.
